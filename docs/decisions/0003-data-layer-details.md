# 0003. Детали слоя данных v0.1

Дата: 2026-10-12 · Статус: принято

## Решения

- **База открывается асинхронно** (`openDatabaseAsync`), затем миграции и сид; экраны рендерятся только после этого. `db` — прокси, который бросает ошибку при обращении до открытия. Так одинаково работает iOS, Android и web-превью.
- **Названия встроенных этапов не хранятся в базе.** У встроенного этапа `name = ''`, подпись берётся из i18n по `key`, пока пользователь не переименует этап. Смена языка сразу меняет названия.
- **Цвет этапа — ключ палитры** (`blue`, `amber`…), а не hex: тема меняет оттенок без миграций.
- **У этапа есть флаг `hidden`** («скрыть из выбора»): этап не предлагается при смене этапа, отклики в нём остаются.
- **Фильтры и сортировка списка, настройка столбцов и сортировка таблицы** хранятся в `settings` (JSON, проверка `zod`). Текст поиска не сохраняется — он живёт в Zustand и общий для списка и таблицы.
- **Удаление в 0.1 — настоящее** (`DELETE`, история удаляется каскадом). Мягкое удаление через `deletedAt` включим вместе с синхронизацией в 0.3.
- **Нормализованная зарплата** `salaryMonthlyGross` считается в репозитории при каждом сохранении: середина диапазона, перевод в месяц (Австрия ÷ 14, остальные ÷ 12, час × 173,3); нетто не сравнивается и даёт `null`.
- **Порядок этапов и столбцов** меняется кнопками «выше/ниже», без библиотеки перетаскивания: это доступно для VoiceOver и не добавляет зависимость. Перетаскивание можно добавить позже.
