# PRD: трекер откликов на вакансии

Рабочее название: **JobTracker** (поменять, когда придумаем имя).
Статус документа: живой. Меняется вместе с решениями; задачи живут в GitHub Issues.

## 1. Суть

Мобильное приложение для тех, кто ищет работу: гибкая таблица откликов, которая заполняется сама. Пользователь делится ссылкой на вакансию, приложение раскладывает её по столбцам, ведёт этапы воронки и напоминает, кому написать. ИИ помогает там, где без него никак (дозаполнение, письма, статусы из почты), и живёт в Pro.

**Первый рынок:** DACH (Австрия, Германия, Швейцария), языки интерфейса ru / de / en.

**Для кого:**
- активно ищущие работу (после сокращения, выпускники, джуниоры): 30–200 откликов, нужен порядок;
- присматривающиеся (работают, но смотрят рынок): мало откликов, важны удобство и напоминания.

## 2. Принципы

1. **Сначала локально.** Версия 0.1 работает целиком на телефоне, без аккаунта и сервера.
2. **Минимум ручного ввода.** Всё, что можно вытащить из страницы бесплатно (разметка, мета-теги, словари), вытаскиваем без ИИ.
3. **ИИ — помощник без прав.** Он только заполняет поля по схеме; результат проверяется и показывается пользователю с пометкой.
4. **Ничего не отправляем за пользователя.** Письма и отклики готовим как черновики.
5. **Дизайн — часть продукта.** Свои токены и компоненты, светлая и тёмная тема с первого дня.

## 3. Версии

| Версия | Цель | Что входит |
|---|---|---|
| **0.1 MVP** | Заменить личную табличку | трекер, этапы, таблица, добавление по ссылке с разбором на устройстве |
| **0.2 Бета** | Удобно каждый день, публичная бета | «Поделиться», импорт/экспорт, свои столбцы, напоминания, главная с воронкой |
| **0.3** | Аккаунт и ИИ | вход Apple/Google, синхронизация, серверный разбор и ИИ-дозаполнение с квотами |

| **0.5** | Магия | статусы из пересланных писем |
| 1.x | Рост | лента вакансий, виджеты, ИИ на устройстве, расширение для браузера |

## 4. Функции

### 4.1 Трекер (0.1)
- Отклик: создать, изменить, в архив, удалить. Обязательны только должность и компания.
- Этапы воронки по умолчанию (см. 5.2), настраиваемые: имя, цвет, порядок, тип (активный/закрытый).
- Смена этапа пишет историю (`stage_events`); в карточке виден таймлайн.
- Главный список сгруппирован по активным этапам; закрытые — в «Архиве».
- Поиск по компании, должности, заметкам; фильтры по этапу, формату, наличию зарплаты, сроку; сортировка.

### 4.2 Таблица (0.1, свои столбцы — 0.2)
- Столбцы по умолчанию: Компания (закреплена), Должность, Этап, Брутто/мес, Формат, Стек, Срок, Обновлено.
- Горизонтальный скролл, сортировка тапом по заголовку, итоговая строка (количество, медиана зарплаты).
- Показать/скрыть/переставить столбцы; настройка хранится локально.
- Свои столбцы (0.2): текст, число, дата, список, флажок. Значения — в `applications.custom`.

### 4.3 Добавление вакансии
**Способы:** вставить ссылку (0.1), «Поделиться» из браузера и приложений (0.2), вставить текст объявления (0.1), импорт CSV/XLSX (0.2), вручную (0.1).

**Разбор ссылки (0.1, на устройстве):**
1. Загрузка страницы: только http/https, таймаут 8 c, до 3 МБ, только HTML, JavaScript не выполняется.
2. JSON-LD `JobPosting` → должность, компания, город, страна, удалёнка, зарплата, даты, занятость, описание.
3. Мета-теги (`og:title`, `og:site_name`, `<title>`) — запасной вариант.
4. Эвристики: зарплата (регулярки DE/EN), формат (remote/hybrid/Homeoffice), занятость (Vollzeit/Teilzeit), стек по словарю.
5. Слияние: разметка > мета > эвристики. У каждого поля запоминается источник (`fieldSources`) и показывается метка.
6. Канонизация ссылки (без utm/gclid/якоря) и `urlHash` для поиска дублей.

**Зарплата:** приводим к брутто в месяц. Годовую сумму для Австрии делим на 14 выплат, для остальных стран — на 12. Нетто помечаем отдельно.

**Если разобрать не вышло** (логин, нет HTML): предлагаем вставить текст объявления или открываем ручную форму с уже подставленной ссылкой. Тупиков нет.

**Серверный разбор и ИИ (0.3):** если на устройстве не хватило ключевых полей, ссылка уходит на `/ingest`: защищённый загрузчик (SSRF), общий кэш по `urlHash`, ИИ-дозаполнение маленькой моделью по JSON-схеме.

### 4.4 Напоминания (0.2)
- «Напомнить через 3/7/14 дней» или дата — локальные уведомления.
- Авто-напоминание, если на этапе «Отправлено» нет движения N дней (по умолчанию 7).
- Утренняя сводка в выбранное время: сколько ждут ответа, какие сроки сегодня.

### 4.5 Импорт и экспорт (0.2)
- CSV и XLSX: выбор файла → сопоставление столбцов (авто по названиям ru/de/en) → предпросмотр → импорт.
- Экспорт CSV (UTF-8 с BOM) с защитой от формул.

### 4.6 Аккаунт и синхронизация (0.3)
- Приложение работает без входа. Вход через Apple и Google нужен для синхронизации и ИИ.
- Синхронизация last-write-wins по `updatedAt`, мягкое удаление (`deletedAt`), RLS на сервере.
- Удаление аккаунта и всех данных из приложения.

### 4.7 ИИ и Pro (0.3–0.5)
- ИИ-дозаполнение: бесплатно ограниченное число в месяц, в Pro без лимита.
- CV: загрузка PDF, несколько версий.
- Сопроводительное письмо DE/EN по CV и вакансии; только факты из CV; черновик, не отправка.
- Статусы из почты (0.5): личный адрес для пересылки, классификация письма в фиксированный набор статусов, сдвиг только вперёд (кроме отказа), журнал и отмена.

### 4.8 Бесплатно и Pro

| Бесплатно | Pro |
|---|---|
| трекер, таблица, свои этапы и столбцы | ИИ-дозаполнение без лимита |
| добавление по ссылке и «Поделиться» (разбор без ИИ) | ИИ-письма DE/EN |
| импорт/экспорт, напоминания, сводка | статусы из почты |
| ИИ-дозаполнение: N в месяц | лента вакансий (1.x) |

Формы оплаты: месяц, пропуск на 3 месяца, пакеты разовых ИИ-кредитов. Цены — после беты.

## 5. Данные

### 5.1 Модель (SQLite через Drizzle; на сервере зеркально в Postgres)

```ts
applications {
  id: string            // uuid
  url?: string          // канонизированная ссылка
  urlHash?: string      // sha256(url) — дубли и кэш
  source?: string       // домен
  title: string
  company: string
  city?: string
  country?: string      // ISO-2, нужен для правила ÷14
  workMode?: 'onsite' | 'hybrid' | 'remote'
  salaryMin?: number
  salaryMax?: number
  salaryCurrency?: string
  salaryPeriod?: 'hour' | 'month' | 'year'
  salaryIsNet?: boolean
  salaryMonthlyGross?: number   // нормализованное значение для сортировки
  employmentType?: 'full_time' | 'part_time' | 'contract' | 'internship' | 'other'
  stack: string[]       // JSON
  language?: string     // язык объявления
  postedAt?: string     // ISO-дата
  deadline?: string
  description?: string  // чистый текст, ≤ 20 000 символов
  stageId: string
  notes?: string
  contactName?: string
  contactEmail?: string
  custom: Record<string, unknown>          // свои столбцы (0.2)
  fieldSources: Record<string, 'markup' | 'meta' | 'heuristic' | 'ai' | 'user'>
  createdAt: string
  updatedAt: string
  archivedAt?: string
  deletedAt?: string    // 0.3, для синхронизации
}

stages        { id, key, name, color, position, kind: 'active' | 'closed', needsAction: boolean, hidden: boolean }  // name '' = встроенное имя из i18n; color — ключ палитры
stage_events  { id, applicationId, fromStageId?, toStageId, at }
settings      { key, value }                                   // JSON-значения
custom_columns{ id, name, type: 'text'|'number'|'date'|'select'|'checkbox', options?, position, visible }  // 0.2
reminders     { id, applicationId, dueAt, notificationId, doneAt? }                                         // 0.2
```

### 5.2 Этапы по умолчанию

| key | Название | Тип | Нужно действие |
|---|---|---|---|
| wishlist | Хочу подать | активный | — |
| applied | Отправлено | активный | — |
| acknowledged | Получено | активный | — |
| action | Нужен ответ | активный | да |
| test | Тестовое | активный | да |
| interview | Интервью | активный | да |
| offer | Оффер | активный | да |
| rejected | Отказ | закрытый | — |
| withdrawn | Не актуально | закрытый | — |

## 6. Нефункциональные требования

- **Скорость:** список и таблица на 500 откликов скроллятся без рывков; разбор ссылки обычно ≤ 3 c.
- **Оффлайн:** всё, кроме разбора ссылок и ИИ, работает без сети.
- **Доступность:** зоны нажатия ≥ 44 pt, подписи у иконок, контраст текста ≥ 4.5:1, крупный шрифт системы не ломает вёрстку.
- **Темы:** светлая и тёмная, по системе или вручную.
- **Локализация:** все строки через i18n; даты и деньги через `Intl` с локалью.
- **Приватность:** в 0.1–0.2 данные только на устройстве; аналитика без персональных данных и с согласием.

## 7. Безопасность

- Чужая страница — недоверенные данные: лимиты размера и времени, без выполнения JS, хранить чистый текст.
- Серверный загрузчик (0.3): только http/https и порты 80/443, проверка IP на каждом редиректе (никаких приватных, loopback, link-local, metadata), максимум 3 редиректа, изолированная функция без секретов.
- ИИ: ключ только на сервере; текст вакансии в тегах как данные; ответ строго по схеме и через валидацию; в вызов разбора не попадают CV и другие данные пользователя.
- Общий кэш наполняется только из серверной загрузки, не из вставленного текста.
- Экспорт CSV экранирует формулы.
- Фишинговые ссылки (0.3): проверка через Google Web Risk.

## 8. Метрики

- Активация: добавил ≥ 3 вакансий в первый день.
- Доля ссылок, разобранных без ручного ввода должности и компании (цель ≥ 80%).
- Удержание D7 и D30.
- Конверсия во Pro, средние расходы на ИИ на платящего (цель ≤ 25% цены подписки).

## 9. Не делаем (пока)

- Автоматическую отправку откликов и писем.
- Массовый парсинг сайтов вакансий (LinkedIn, Indeed, karriere.at и т.п.).
- Веб-версию и расширение для браузера — после 1.0.
