# Бэклог JobTracker

Исходный план. `scripts/create-backlog.mjs` превращает его в GitHub Issues: каждый раздел `##` становится вехой (milestone), каждый `###` — задачей. После импорта источник правды — GitHub; этот файл не обновляем.

Формат задачи: строка `labels:` (тип, область, приоритет, размер), строка `depends:` (ключи задач, которые надо сделать раньше), дальше описание. Размеры: S — до полудня, M — 1–2 вечера, L — несколько вечеров.

## v0.1 MVP
> Приложение заменяет личную табличку: трекер, этапы, таблица, добавление по ссылке с разбором прямо на телефоне. Без сервера и аккаунта.
